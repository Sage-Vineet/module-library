# MySage Reusable Email Module

Enterprise reusable email module using Node.js and React.

## Features

- Welcome email API
- OTP email API
- React frontend integration
- SMTP support
- Reusable architecture
- Enterprise-ready module structure

## Backend Run

```bash
cd backend/email-module
npm install
npm run dev
```

## Frontend Run

```bash
cd frontend
npm install
npm run dev
```

## API Endpoints

POST /api/email/welcome
POST /api/email/otp
